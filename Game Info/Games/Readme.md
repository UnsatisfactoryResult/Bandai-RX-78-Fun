Here you can find games to burn and play on hardware or emulator.

Note that games come in a few formats.

Cassette games:
There were official and type-in games released on cassette tapes. You'll need to use the BS-BASIC cart, and load the wav file from the prompt.

Cartridge games:
Cartridge games were released on single chip 8/16/32kb ROMs, and dual chip 8/16kb ROMs.

You may see multiple versions of a game: emulator and flashable
Games are tested on the eRX-78 emulator, and the "emulator" version of a game will work on it.
Games marked "flashable" are meant to be burned to a modern 27C256 OTP PROM with my reproduction PCB, and are usable on real hardware.
